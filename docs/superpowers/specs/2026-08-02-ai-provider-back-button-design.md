# AI 服务商页面箭头返回键设计

## 目标

优化 AI 服务商列表页与新增/配置服务商页的顶部返回控件，使其贴近用户提供的 iOS 参考图：视觉上只保留左箭头，不显示“设置”或“服务商”文字；两个页面使用同一套尺寸、位置和交互反馈。

## 设计

- 返回控件使用清晰的左箭头图标，不依赖单字符文本字形，避免不同系统字体造成箭头粗细和垂直对齐不一致。
- 控件保持顶部左侧导航位置，拥有至少 44px 的宽高触控区；默认状态透明，仅保留轻量圆形边框，避免遮挡居中的页面标题。
- 通过 `aria-label` 明确表达返回目标（“返回设置”或“返回服务商”），并保留键盘焦点环；按下时只使用不影响布局的透明度/缩放反馈。
- `prefers-reduced-motion: reduce` 下关闭过渡和缩放，保留颜色/边框的静态可见状态。
- 返回行为、导航栈、边缘返回手势不变；本次只调整控件呈现与可访问性。

## 验证

- 源码回归测试确认两个 provider 页面都渲染箭头图标、正确的 `aria-label` 和统一 class。
- CSS 回归测试确认 44px 命中区、圆形边框、按下反馈、焦点样式与 reduced-motion 覆盖。
