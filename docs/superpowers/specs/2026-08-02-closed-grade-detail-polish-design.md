# AI Reader 闭源级细节体验收口设计规格

**日期：** 2026-08-02  
**状态：** 待评审  
**范围：** 书库空状态与搜索恢复、AI 服务商空状态与保存条件、最小触控尺寸、少量文案和图标一致性

## 背景

AI Reader 已完成书库、阅读、设置、AI 服务商、长内容会话、错误重试、reduced motion、焦点恢复和本地数据持久化等主要能力。当前体验问题不再集中在架构缺失，而是少数边缘状态仍会让用户犹豫：同屏出现多个同义动作、禁用按钮没有原因、搜索无结果后缺少恢复入口，以及个别按钮和字符图标没有完全收口。

本轮目标不是重新设计产品，而是在不改变核心流程和数据模型的前提下，把高频入口与失败状态打磨到可预测、可恢复、可解释的闭源产品标准。

OpenMinis 仅作为交互原则参考：借鉴原生分组、状态表达、单一主动作和决策点说明，不复制其 GPLv3 源码、图片、图标、SF Symbols 用法或工程结构。本项目继续使用独立的 React/TypeScript 实现和现有许可。

## 目标

1. 每个空状态只呈现一个视觉主动作，避免用户判断两个同义入口的差异。
2. 所有不可继续的状态都在操作附近解释原因，并给出下一步。
3. 搜索、筛选、导入和服务商配置均不存在无出口的死路。
4. 高频触控目标在真实移动视口下至少为 `44 × 44px`。
5. 保持安静、原生、阅读优先的产品气质，不增加装饰动画、营销文案或新的视觉系统。
6. 不改变已有书籍、进度、分组、设置、AI 服务商和备份数据。

## 非目标

- 不重构根导航、阅读标签或书库信息架构。
- 不重构阅读器悬浮控制、选区工具条或高亮颜色流程；这些需要独立设计和实书验证。
- 不重新组织设置页分组，不恢复已经明确移除的四条开关说明文案。
- 不新增 AI 服务商协议、模型发现能力、Provider Schema 或远端同步。
- 不引入新的图标依赖、设计系统、Skeleton 框架或全局动画。
- 不复制 OpenMinis 的源码、资源或 GPL 代码结构。

## 设计原则

### 一个状态，一个主动作

空状态可以保留说明和次动作，但同一任务只能有一个视觉主按钮。工具栏入口应在内容存在、用户进入管理模式后再出现。

### 在决策点解释

隐私说明应出现在首次选择文件之前；保存条件应出现在保存按钮附近；错误信息应说明发生了什么以及用户能做什么。

### 默认安静，必要时说清楚

正常状态保持简洁。说明文字只用于隐私、能力限制、错误恢复和不可用原因，不给所有设置项增加永久副文案。

### 保留上下文和草稿

清除搜索只清除查询词，不同时改变分组筛选。模型刷新失败不清空已有模型。配置校验失败不丢失草稿。

## 详细设计

### 1. 书库空状态

#### 状态规则

| 状态 | 顶部导入 | 页面主动作 | 辅助信息 |
|---|---|---|---|
| 正在加载 | 隐藏 | 无 | 保留现有加载状态 |
| 书库为空 | 隐藏 | `导入图书` | 格式支持和本地存储说明 |
| 书库有书 | 显示 | 由书籍内容决定 | 不重复显示中央导入 |
| 导入失败且仍为空 | 隐藏 | `重新选择文件` | 可行动的错误信息 |

书库为空时，页面文案调整为：

- 标题：`还没有书`
- 说明：`导入 EPUB 或 TXT 后，就可以在这里继续阅读。`
- 隐私说明：复用 `UI_TEXT.LOCAL_STORAGE_ONLY`
- 主按钮：`导入图书`

隐私说明使用辅助文字层级，但必须出现在主按钮附近、首次选择文件之前。它不是全局隐私政策入口的替代品。

#### 导入错误

继续复用现有 `importError` 展示通道，不新增错误中心。错误节点使用 `role="alert"`，主按钮文案切换为 `重新选择文件`。

在现有异常信息足以判断时，映射为以下文案：

- 本地存储不可用：`无法使用本地存储。请退出无痕模式或检查 Safari 设置后重试。`
- 存储空间不足：`本机可用空间不足。请释放空间后重试。`
- EPUB/TXT 解析失败：`无法读取这本书。请确认文件完整且格式为 EPUB 或 TXT。`
- 无法分类：保留 `读取文件失败，请重新选择文件。`

错误分类不得输出文件内容、路径、API Key、浏览器堆栈或内部异常名称。

### 2. 书库搜索与筛选恢复

当前无结果状态只显示标题和查询词。新状态必须根据造成空结果的条件提供单一恢复动作：

| 条件 | 主文案 | 恢复动作 | 执行结果 |
|---|---|---|---|
| 有搜索词 | `没有找到匹配的图书` | `清除搜索` | 只清空 `searchQuery`，保留当前分组 |
| 无搜索词且当前为具体分组 | `这个分组还没有图书` | `查看全部图书` | 切换到“全部”，不改变视图模式 |
| 搜索词和具体分组同时存在 | `没有找到匹配的图书` | `清除搜索` | 优先移除限制更强的搜索条件 |

若清除搜索后当前分组仍为空，页面自然进入第二种状态并显示 `查看全部图书`。不在同一状态同时显示两个恢复按钮。

恢复后，焦点返回搜索框或分组入口；不得跳到页面顶部、切换封面/列表模式或清除编辑状态之外的用户偏好。

### 3. AI 服务商空状态

#### 无服务商

当 `settings.providers.length === 0` 时：

- 隐藏顶部 `编辑`。
- 隐藏顶部添加菜单，避免与中央主动作重复。
- 保留空状态标题 `还没有添加 AI 服务商`。
- 以全宽 `添加 AI 服务商` 作为唯一主动作。
- 在主动作下提供低权重文字按钮 `导入服务商配置`。
- 保留现有 API Key 与发送内容说明。

`导入服务商配置` 是次动作，不使用填充背景，不与主按钮竞争视觉重量。导入完成或添加首个服务商后，恢复顶部 `编辑` 和添加菜单。

若删除最后一个服务商，必须同步退出 `providerListEditing`、关闭添加菜单，并进入上述空状态，不能留下无对象可编辑的工具栏。

#### 有服务商

有至少一个服务商时保持现有结构：

- 顶部显示 `编辑` 和添加菜单。
- 添加菜单包含 `添加 AI 服务商` 与 `导入服务商配置`。
- 列表行继续显示状态、凭据摘要、模型数量和当前使用状态。

本轮不改变服务商分组、删除确认和页面推入结构。

### 4. 配置保存条件

继续保留禁用的 `保存并使用` 按钮，但必须在 sticky action 区域内显示一行中性说明，解释当前还缺少什么。

从配置草稿派生 `missingRequirements`，顺序固定为：

1. 服务商类型
2. 名称
3. API 地址
4. API Key
5. 模型

文案规则：

- 缺一项：`填写 {字段} 后即可保存`
- 缺两项：`填写 {字段 1} 和 {字段 2} 后即可保存`
- 缺三项及以上：`请完成必填信息后保存`
- 模型列表为空且未选择手动模型：`刷新模型，或手动添加模型后即可保存`
- 条件完整：隐藏说明，不额外显示“可以保存”

说明文字通过 `aria-describedby` 与按钮关联，并使用现有 inline-status 视觉层级；它不是错误提示，不使用红色。字段失焦后可以显示既有的就近校验，但首次打开页面时不把所有空字段标红。

`saveDraft` 提交时仍需再次执行同一套校验，不能只依赖按钮的 `disabled` 状态。校验失败保留草稿和当前滚动位置。

### 5. 最小触控尺寸

书库空状态主按钮在实际页面中低于 44px。本轮为相关主按钮设置稳定的 `min-height: 44px`，并验证文字放大后仍能自然增高。

约束：

- 不使用固定 `height` 截断多行文字。
- 不通过透明伪元素制造与可见位置不一致的点击区域。
- 图标按钮的可点击盒至少 `44 × 44px`，图标本身保持 16–22px。
- 调整共享 `.primaryButton` 前先确认其所有调用点；若会造成无关页面位移，则新增更窄的空状态变体。

### 6. 文案收口

阅读目标页移除泛化激励表达，改为事实反馈：

- 未完成：`还需 {n} 分钟`
- 已完成：`今日目标已完成`
- 辅助状态：`今日已阅读 {n} 分钟`

`READING_GOAL_SUBTITLE` 调整为 `设置每日阅读时长，进度仅保存在本机。`，避免“提升数据”“激励读完更多图书”等营销式表达。

本轮不增加成就、彩带、连续打卡强化或完成动画。

### 7. 字符图标一致性

只处理本轮触达表面中的字符图标，不进行全应用图标迁移：

- AI 服务商：`+`、`↥`、`›`、`✓`
- 阅读工作区：`•••`

使用项目内独立编写的 24px `viewBox` 描边 SVG，默认 `stroke="currentColor"`，端点和连接使用圆角。装饰图标设置 `aria-hidden="true"`；图标按钮的可访问名称继续由按钮提供。

不新增第三方图标包，不复制 SF Symbols 路径，不复制 OpenMinis 图标资源。若新增共享组件，只创建本轮实际使用的最小图标集合，不建立抽象图标框架。

## 无障碍要求

- 新增恢复动作必须可通过键盘和 VoiceOver 到达。
- 导入失败使用 `role="alert"`；非错误状态更新使用 `role="status"` 或 `aria-live="polite"`。
- 空状态切换后不自动抢走用户正在使用的焦点；由用户触发的恢复动作应把焦点放到下一处合理控件。
- 禁用按钮的说明通过 `aria-describedby` 暴露，不能只依靠颜色或透明度。
- 所有新增按钮保持可见的 `:focus-visible` 样式和至少 44px 触控面积。
- 200% 文本缩放时允许按钮、列表行和 sticky action 区域增高，不产生横向滚动。
- 本轮不新增非必要动画；现有状态淡入必须遵循 reduced motion。

## 数据与兼容性边界

- 不修改 IndexedDB Schema、书籍记录、阅读进度、分组结构或 AI Provider Schema。
- 不改变备份导入导出格式。
- 不改变 API Key 的本地保存与备份排除规则。
- 不改变模型刷新失败时保留已有模型的行为。
- 新增状态全部由现有数据派生，不写入新的持久化字段。
- 现有深色、浅色、系统主题和自定义背景必须保持兼容。

## 组件边界

- `LibrarySurface` 负责根据书库、搜索和分组状态选择空状态文案与动作。
- `page.tsx` 或现有导入边界负责把安全的错误类别映射为用户文案；展示组件不解析浏览器异常。
- `AiSettingsSurface` 负责服务商空状态、工具栏显隐和配置缺失项展示。
- AI Provider 的必填判断应提取为可单测的纯函数，供 `canSave`、提示文案和提交校验共同使用。
- `page.module.css` 只增加必要的触控尺寸、辅助说明和次动作样式，不新增一套表面或阴影 Token。
- `uiText.ts` 承载新增用户文案，避免在多个组件重复硬编码。

## 实施顺序

### 批次 A：可恢复性与可解释性

1. 书库空状态动作去重、隐私说明和 44px 主按钮。
2. 搜索/分组无结果恢复动作。
3. AI 服务商空状态工具栏收口。
4. 配置保存条件说明与共享校验。

### 批次 B：安静一致性

1. 阅读目标事实型文案。
2. 本轮触达表面的字符图标替换。

批次 A 完整通过验证后再进入批次 B。两个批次不得夹带设置页重排、阅读器工具条重构或新的动效实验。

## 验证策略

### Vitest / 源码集成测试

- 书库为空时顶部导入隐藏，中央主动作和本地存储说明存在。
- 书库有书时顶部导入恢复。
- 导入错误节点具备 alert 语义且文案不泄漏内部信息。
- 有搜索词时显示 `清除搜索`，执行后保留当前分组。
- 空分组显示 `查看全部图书`，执行后保留当前视图模式。
- 服务商为空时不显示 `编辑` 和顶部添加菜单，显示一个主动作和一个次动作。
- 删除最后一个服务商后退出编辑状态。
- 缺失项纯函数覆盖单项、两项、多项、模型缺失和完整状态。
- 保存按钮说明与 `aria-describedby` 正确关联，提交校验不丢草稿。
- 设置页四条开关说明仍保持移除状态。
- 阅读目标不再包含激励式旧文案。
- 本轮替换的装饰图标具备 `aria-hidden`，图标按钮仍有可访问名称。

### Playwright / 移动视口

在 iPhone 15 Pro Max 视口验证：

1. 新访客空书库只有一个主导入动作，主按钮高度至少 44px。
2. 导入一本测试书后顶部导入出现，空状态消失。
3. 搜索不存在的书名后可清除搜索，并恢复原分组结果。
4. 空分组可返回全部图书。
5. 服务商为空时没有无意义的编辑按钮和重复添加入口。
6. 配置缺少 API Key、地址或模型时，sticky action 能说明原因。
7. 200% 文本缩放、深浅主题和 reduced motion 下无横向溢出或内容遮挡。
8. VoiceOver/键盘顺序与视觉顺序一致。

测试不得使用真实 API Key，不得依赖 OpenMinis 资源，不得修改生产站点中的真实用户数据。

## 成功标准

满足以下条件后，本设计视为实现完成：

- 空书库和空服务商页面各只有一个视觉主动作。
- 搜索和分组无结果状态均可在一次点击内恢复。
- 用户无需试错即可知道 `保存并使用` 缺少什么条件。
- 本轮涉及的所有主按钮和图标按钮触控盒不小于 44px。
- 导入错误对用户可行动、对辅助技术可感知、对内部信息无泄漏。
- 阅读目标文案保持事实型、安静、非营销。
- 不新增持久化字段，不破坏既有数据和备份兼容性。
- 焦点、reduced motion、200% 文本、浅色和深色主题验证通过。
- 全量测试、Lint、生产构建、目标 Playwright 和 `git diff --check` 全部通过。

## 明确保留的后续议题

以下问题有价值，但需要独立的实书和实体 iPhone 验证，不进入本轮：

- 选中文本后将高亮与问 AI 合并为上下文工具条。
- 高亮单击复用上次颜色、二级展开选择其他颜色。
- 首次阅读时增加一次性的“轻点正文显示控制”教学。
- 统一“藏书 / 分组 / 书库”的产品术语。
- 加载书库时用几何稳定的轻量 Skeleton 代替纯文本。
