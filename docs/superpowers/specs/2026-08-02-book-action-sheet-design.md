# 图书操作 Sheet 视觉层级设计

## 状态

- 状态：已确认
- 日期：2026-08-02
- 目标表面：移动端「图书操作」底部 Sheet
- 参考：[`coss.com/ui`](https://coss.com/ui)，重点参考 Drawer、Card、Button 的分组和状态语言

## 问题

当前面板的功能完整，但操作组、详情组和危险操作区的视觉权重接近，图标容器偏小，边框与圆角叠加后显得像一组廉价卡片。用户在第一眼无法快速分辨主要操作、次要信息和破坏性操作。

## 目标

保留现有底部 Sheet 的路由、拖拽关闭、滚动、焦点恢复和所有业务行为，只通过结构化分组、间距、边框、图标容器和触摸状态，建立更克制、更接近原生工具的视觉层级。

## 非目标

- 不更换 Sheet 基础组件或导航模型。
- 不增加新的图书操作，不改变已有操作的文案和执行逻辑。
- 不引入新的 UI 依赖、字体、图片或外部资源。
- 不把图书操作改成独立页面或桌面端侧栏。

## 设计决策

### 1. Sheet 外壳

继续使用现有 `book-actions` 路由和拖拽条。面板保持可滚动和 `max-height` 约束，顶部标题与关闭按钮沿用全局 Sheet 标准。内容区使用稳定的左右内边距和较短的垂直节奏，避免内容贴边或被底部安全区截断。

### 2. 书籍信息头部

封面、书名、格式/大小、阅读进度组成一个紧凑的 hero 区。封面保持可识别但不喧宾夺主，标题使用最强的正文层级，元数据使用次级颜色和较小字号。标题超长时继续单行截断，不能撑破 Sheet。

### 3. 操作分组

主要操作放在一个完整分组中，使用单一细边框和统一分隔线，不叠加厚阴影。每个操作行保持至少 44px 的触摸高度，图标使用统一尺寸和圆角方形底，不再使用过小的装饰性图标。蓝色只用于操作图标和交互状态，默认文字仍使用主文字色。

### 4. 详情分组

详情区使用与操作区一致的容器语言，但降低视觉权重。标题作为小型分组标签，字段采用左侧标签、右侧值的 key-value 布局；值保持右对齐并在窄屏截断，分隔线与操作区一致。

### 5. 危险操作

删除动作单独成组，保留明确的红色语义，但不使用大面积红底。图标与文字使用同一危险色，触摸反馈使用浅红色填充。这样能让删除动作清晰可见，同时不会与主要操作竞争。

### 6. 状态与可访问性

所有按钮保留原有可访问名称、键盘行为和焦点恢复。新增或调整的视觉状态包含 hover、active、focus-visible、disabled（若已有）。不新增装饰性动画，沿用项目现有 motion token 和 reduced-motion 规则。

## 完成标准

- 图书操作 Sheet 在 iPhone 14、iPhone 15 Pro Max viewport 下不出现横向溢出。
- 主要操作、详情、删除三个层级可在首屏或一次自然滚动内区分。
- 操作行触摸高度不少于 44px，键盘/焦点回归不受影响。
- 浅色、深色和 sepia 主题均使用已有语义 token，不写死背景色。
- 现有 book-actions 相关 E2E 行为测试全部通过，并新增至少一条视觉契约回归。
