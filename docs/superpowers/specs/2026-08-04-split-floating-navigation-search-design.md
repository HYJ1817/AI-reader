# AI Reader 分离式悬浮导航与搜索设计

**日期：** 2026-08-04
**状态：** 已确认，待实施
**范围：** 根导航 Dock、书库搜索 Push 页面、共享布局过渡、高频按压反馈、TXT 中文排版
**参考：** 用户提供的“宽胶囊导航＋独立搜索按钮”和“返回按钮＋底部搜索框”截图

## 目标

在保留书库、阅读、设置三个根入口的前提下，将底部导航改为左侧宽胶囊与右侧独立搜索按钮。搜索不成为第四个根标签，而是书库上方的临时 Push 页面。进入搜索时，左侧导航收缩成返回按钮，右侧搜索按钮连续扩展成搜索框；返回时完整反向播放。

实现必须复用现有书库数据、查询逻辑、列表/网格模式、NavigationStack、主题 Token 和 motionSystem，不复制参考软件的功能、图标或素材。

## 默认导航 Dock

### 结构

- Dock 固定在底部安全区上方，由一个持久化容器承载。
- 左侧为宽幅悬浮胶囊，包含书库、阅读、设置三个现有入口。
- 右侧为独立圆形搜索按钮，语义标签为“搜索书库”。
- 搜索只在普通根页面显示；阅读器、Sheet、批量编辑和已有 Push 页面继续遵循现有显隐策略。
- 三个根入口的顺序、含义和点击行为不变。

### 视觉

- 左胶囊使用现有主题感知半透明材质、14px 有界模糊、0.5px 边框和克制阴影。
- 选中项保留独立浅色椭圆底板，激活图标和文字使用主文字色。
- 搜索圆钮与左胶囊使用相同高度、材质、边框和阴影语言。
- 图标使用项目自有 SVG，略加大并统一视觉重量，不复制参考图资产。
- 左胶囊与搜索圆钮之间保留约 8–10px 间距；整个 Dock 与屏幕两侧保留约 10–14px 安全边距。
- 所有可点击区域至少 44×44px，支持浅色、深色和护眼色。

## 搜索页面

### 导航模型

- 在现有 `PushRoute` 中增加 `library-search`，由 `NavigationStack` 呈现。
- 搜索入口只改变 Push 栈，不改变当前根标签。若从阅读或设置打开搜索，搜索仍展示同一个书库数据源；返回后恢复原根标签。
- 浏览器返回、边缘返回手势和左下返回按钮统一调用 NavigationStack 的 `pop`。
- 关闭后焦点恢复到独立搜索按钮。

### 内容

- 搜索页面顶部区域展示书库图书，不增加小说、漫画、书店、有声书或分类数据。
- 初始查询为空时展示全部书库图书。
- 输入后复用现有 `filterBooksByQuery`，按书名和来源即时过滤。
- 结果严格跟随书库当前显示模式：书库为列表时显示列表，书库为网格时显示网格。
- 在书库切换显示模式后再次进入搜索，搜索页使用最新模式；搜索页不新增第二套模式状态。
- 点击图书继续调用现有打开阅读器行为；更多操作继续调用现有图书操作 Sheet。
- 当前书库分组筛选不限制全局搜索结果。搜索覆盖全部书库，避免用户误以为图书不存在。

### 底部搜索 Dock

- 搜索模式下，左侧宽导航变为圆形返回按钮。
- 右侧搜索圆钮扩展为占据剩余宽度的搜索框，搜索图标保持在原来的视觉轨迹上。
- 输入框使用 `type="search"`、清晰的可访问标签和现有占位文案。
- 搜索扩展完成后自动聚焦输入框，避免软键盘在几何变形中途改变 VisualViewport。
- 返回时先提交退出意图并让输入框失焦，Dock 从当前几何反向变形；不要求用户手动关闭键盘。

### 状态

- 空书库：显示现有空书库说明与导入入口，不显示无结果文案。
- 有书但无匹配：显示“没有匹配的图书”、当前查询和“清空搜索”。
- 清空查询：立即恢复全部图书并保持输入焦点。
- 导入、存储错误和图书加载状态继续使用现有安全文案与恢复行为。
- 200% 文本下搜索框、返回按钮和结果内容不得横向溢出或遮挡。

## 共享布局过渡

### 持久化原则

默认 Dock 和搜索 Dock 不作为两个互斥组件硬切换。外层 Dock、左槽位和右槽位保持挂载，只切换模式与内容。Motion 只在合成层上完成几何连续性。

### 进入搜索

1. 点击搜索圆钮后，三个根标签在约 80–100ms 内淡出并轻微缩小。
2. 左侧宽胶囊从当前宽度收缩为与搜索按钮等大的圆形返回按钮。
3. 右侧搜索圆钮保留搜索图标，同时向左扩展为搜索框。
4. 搜索结果页面使用短交叉淡入，不做大幅上下位移。
5. 宽度变形接近完成后挂载可编辑输入态；布局动画完成后聚焦输入框。

### 返回

1. 返回按钮、浏览器返回或边缘手势触发相同退出状态。
2. 搜索框从当前宽度收回独立圆钮，输入文本淡出。
3. 左侧返回圆钮展开为宽胶囊，三个根标签按原激活状态恢复。
4. 搜索结果页面淡出，原根页面保持原滚动位置，不重新挂载。

### 动画参数

- 使用 `motion/react` 的共享布局或 layout transform，不直接逐帧动画 `left`、`width` 等布局属性。
- 总时长约 280ms，使用现有导航强调缓动，不使用 bounce 或 elastic。
- 搜索内容和标签内容的交叉淡化不超过 120ms。
- 动画必须可中断。快速连续点击或中途返回时，从当前几何继续，不跳到起点或终点。
- 应用或系统 Reduced Motion 下取消几何缩放，改为不超过 100ms 的交叉淡化，并在下一帧聚焦输入框。
- Dock 只保留一个实时 `backdrop-filter` 层，内部选中底板、返回按钮内容和搜索输入不新增移动模糊层。

## 按压反馈契约

- 根标签、搜索按钮、返回按钮和主 CTA 按下时下移约 1px，并缩放到约 0.97。
- 图标可在父控件内部缩放到约 0.94，形成明确但克制的触感。
- 内容型图书行继续使用背景染色和 1px 位移，不强制整行缩小。
- 使用现有 `--motion-fast` 与标准缓动；Reduced Motion 下取消缩放和位移。
- 不增加控制所有按钮的全局 React hook，也不对全部 `button` 写全局 `:active`，避免覆盖 Motion 的 transform。

## TXT 中文排版

- TXT 渲染时对包含汉字的段落标记 `lang="zh-CN"`，英文段落不标记。
- 中文段落使用 `line-break: strict`、`word-break: normal`，并保留 `overflow-wrap: break-word` 作为长链接兜底。
- 浏览器支持时启用 `hanging-punctuation`，不将其作为基本布局依赖。
- 保留当前段间距、默认行高和用户可调字号、字距、词距、页边距与对齐设置。
- 不自动增加首行缩进，避免误处理章节标题、诗歌和短句。
- EPUB 继续尊重原书样式，不套用 TXT 段落规则。

## 架构边界

- `AppNavigation` 扩展为持久化的双槽 Dock，并接收搜索模式、进入搜索和返回搜索行为。
- `library-search` Push 页面复用书库的图书集合、查询函数、当前 view mode 和图书交互回调。
- 搜索查询可以继续使用当前页面级状态，但进入新搜索时默认清空，退出后不污染书库主页展示。
- 若复用现有 `LibrarySurface` 会导致主页标题、编辑动作或顶部搜索框重复，则提取只负责书架结果的内部展示组件；不复制列表与网格渲染逻辑。
- 搜索输入的 ref 与动画完成回调集中在 Dock/搜索页面边界，避免散落的定时器。

## 非目标

- 不增加第四个根标签。
- 不新增小说、漫画、书店、有声书、分类或远程搜索。
- 不复制参考软件源码、图标、商标、背景图或私有动画。
- 不重写 NavigationStack、motionSystem、阅读器或 Sheet 架构。
- 不改变空书库的文案策略和深色背景层级。
- 不新增阅读设置持久化字段。

## 风险控制

- iOS 软键盘会改变 VisualViewport，因此输入焦点推迟到 Dock 几何基本完成后，并覆盖动画中返回场景。
- 搜索页展示全部书库而非当前分组，必须在文案和测试中保持一致，避免隐式筛选。
- 列表/网格展示只能共享一个 view mode 状态，防止两个页面模式漂移。
- 快速进出搜索可能产生陈旧回调，动画完成和焦点操作必须校验当前 `navigation.state.revision`，过期回调直接忽略。
- 搜索 Dock 扩展期间不新增第二个实时玻璃层，避免 Safari 合成开销和文字穿透。
